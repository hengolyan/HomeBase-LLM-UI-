
## About the Project

HomeBase is an all in one support platform created for lone soldiers in Israel. The application centralizes information about rights, benefits, support organizations, housing assistance, and community resources, while providing an accessible and multilingual user experience tailored to the unique needs of its users.

A demonstration video is included to present the application's functionality, user journey, and interface design in a realistic usage scenario (https://youtube.com/shorts/7q1rHKmdoss?si=R7molOrJGnaI3Oyw) 

As part of the development process, Large Language Model (LLM) technologies were leveraged to support UI prototyping, content generation, design exploration, and application demo creation. The integration of AI-assisted development tools enabled faster iteration, enhanced creativity, and a more user-centered design process.
